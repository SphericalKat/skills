# skills

Agent skills that work with any agent supported by [`skills`](https://github.com/vercel-labs/skills) (Claude Code, Codex, Cursor, OpenCode, pi, and others).

## Install

```sh
npx skills add SphericalKat/skills                  # pick skills interactively
npx skills add SphericalKat/skills --skill deslop   # install one skill
```

## Skills

| Skill | Description |
| --- | --- |
| [deslop](skills/deslop/SKILL.md) | Simplify a completed workpackage without changing its intended behavior. |
